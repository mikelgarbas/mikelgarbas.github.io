# GarBas

Web de GarBas: webs para negocios locales en Bilbao.

## Marca
- `marca/garbas-logo.svg`: logo para fondos claros
- `marca/garbas-logo-blanco.svg`: logo para fondos oscuros
- `marca/garbas-simbolo.svg`: símbolo solo (favicon, avatar)
- `marca/garbas-perfil-redes.png`: foto de perfil para Gmail, Instagram y WhatsApp

Colores: tinta `#17181C`, papel `#F6F6F3`, ámbar `#FFB71B`.
Tipografías: Bricolage Grotesque (títulos y logo), Inter (texto).
